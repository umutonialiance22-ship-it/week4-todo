
# Taskly — Interactive To-Do List

Taskly is a responsive to-do list application built with HTML, Tailwind CSS, JavaScript, and Vite.

## Features

- Add tasks using the button or Enter.
- Validate empty task input.
- Mark tasks as completed or active.
- Delete tasks.
- Filter tasks by All, Active, and Completed.
- Display the number of remaining tasks.
- Clear all completed tasks.
- Save tasks using localStorage.
- Edit tasks by double-clicking their text.
- Assign High, Medium, or Low priority.

## Technologies

- HTML5
- Tailwind CSS
- JavaScript
- Vite
- Browser localStorage

## Run locally

1. Clone this repository.
2. Open the project folder in a terminal.
3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in the terminal.

## Data persistence

Tasks are stored in the browser using localStorage and JSON.
They remain available after refreshing the page in the same browser.

## Security

Task text is inserted using textContent rather than being interpreted as HTML.
